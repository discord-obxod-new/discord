### 📦 Установка и запуск

Перед началом работы строго следуйте инструкции:

1. Скачайте архив из раздела **Releases**.
2. Распакуйте ZIP-архив в любую удобную папку.
3. **Откройте `discord.exe`**.
5. В папке откройте любой подходящий вам bat файл.
6. После завершения перезапустите Discord для применения изменений.

Инструмент не запрашивает и не хранит данные вашей учётной записи. Все изменения вносятся локально и могут быть отменены при необходимости.
